# HaoToolbox

Browser-based tools for comparing and organizing files.

## Compare two CSV snapshots

[Open the English CSV comparison tool](https://haotoolbox.com/en/tools/csv-diff/)

Compare records by their identifier to find added, deleted, and modified records. Preview the differences, copy a summary, or download an English XLSX report with four sheets.

No sign-up is required. Selected CSV files are processed in your browser; the English comparison tool has no analytics tracking. Review the tool's privacy and input limitations before use.
